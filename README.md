# 图片压缩工具

这是一个简单易用的在线图片压缩工具，具有苹果风格的界面设计。用户可以上传图片，预览压缩效果并下载压缩后的文件。

## 在线使用

访问 https://实际的用户名.github.io/图片压缩工具/ 即可在线使用本工具。

## 功能特点

- 支持 PNG、JPG 格式图片上传
- 实时预览压缩前后的图片效果
- 显示压缩前后的文件大小
- 可调节压缩比例
- 支持压缩后图片下载
- 优雅的苹果风格界面设计

## 技术实现

- 使用原生 HTML5 和 CSS3 实现界面
- 使用 JavaScript 实现图片压缩功能
- 采用 Canvas API 进行图片处理
- 响应式设计，适配各种设备
